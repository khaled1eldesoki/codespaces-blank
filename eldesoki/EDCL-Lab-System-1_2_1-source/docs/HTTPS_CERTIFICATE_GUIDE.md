# HTTPS certificate setup (private CA, offline)

**Design.** The server installer creates a private *EDCL Laboratory CA* (10 years) and a server certificate (2 years) signed by it, valid for every name and IP you entered (plus `localhost`). Workstations trust **the CA**, not the individual server certificate. No internet, OpenSSL or PowerShell is needed (certificates are generated by the bundled Node using node-forge).

| File (server `C:\ProgramData\EDCL Server\certs`) | Meaning | Leaves the server? |
|---|---|---|
| ca.key | CA private key | **Never** |
| server.key | server private key | **Never** |
| ca.crt | CA certificate | Yes, to every PC (via `client-config`) |
| server.crt | server certificate | Used by the server only |

**How the workstation trusts it.** The app itself verifies that the server's certificate is signed by `ca.crt` (for the configured server host only) — nothing is added to the Windows certificate store, and any other certificate is refused. Optional: tick "Also trust in Windows" in the client installer only if a PC must open the phone viewer (`https://server:8443/m/`) in a web browser. Manual: `certutil -addstore -f Root ca.crt` (run as administrator).

**Verify.** The client installer shows the CA fingerprint (SHA-256); compare it with `client-config\README.txt` (printed by the server installer). A mismatch means the wrong/unsafe file — stop.

**Server name or IP changed / certificate expiring (check `cert-info.json`):** on the server run `edcl-server-ctl renew-certs 192.168.1.25` then `edcl-server-ctl restart`. The CA is kept, so **no workstation needs any change** (if only the *address* changed, use "Server: change" on the sign-in screen, or reinstall silently with the new /SERVER).

**CA lost or compromised:** delete `certs\ca.*`, run the server installer again, redistribute the new `client-config` and reinstall/refresh each client's ca.crt (installer or sign-in screen → change server → pick ca.crt).

**Back up `certs\ca.key` offline** (USB in a safe). Without it you can still issue nothing new under the old CA.
